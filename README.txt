BETONEXA KİŞİSEL SÜRÜM

1. Bu klasörü GitHub deponuza yükleyin.
2. Vercel'de bu depoyu yayınlayın.
3. Demo giriş şifresi: 1234
4. Veriler bu sürümde kullanılan cihazın tarayıcısında saklanır.
5. Bilgisayar ve telefon arasında otomatik veri eşitleme için sonraki aşamada Supabase bağlantısı eklenmelidir.
6. Ayarlar > Yedeği İndir ile düzenli yedek alın.
